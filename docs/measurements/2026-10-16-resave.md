# Re-save survival, 2026-10-16

One-time measurement, one tool. qpdf 12.4.2 (Homebrew, macOS), poppler `pdfdetach`.
Input: `demo/contract.pdf` at the commit that adds this file.

| qpdf mode | marker line kept | verify the re-saved PDF | attachment listed | attachment bytes = original bundle | verify the attachment |
|---|---|---|---|---|---|
| default | no | REFUSED BUNDLE_MISSING | yes | yes | VERIFIED, NO PAGE |
| `--qdf` | no | REFUSED BUNDLE_MISSING | yes | yes | VERIFIED, NO PAGE |
| `--object-streams=generate` | no | REFUSED BUNDLE_MISSING | yes | yes | VERIFIED, NO PAGE |
| `--recompress-flate` | no | REFUSED BUNDLE_MISSING | yes | yes | VERIFIED, NO PAGE |

Control for the alternative placement: the same PDF with 41 bytes appended after
`%%EOF` (`START_TAIL_MARKER{"x":1}END_TAIL_MARKER`), re-saved in the same four
modes. The appended bytes were present in none of the outputs (`grep -a -c` = 0;
1 in the input).

Commands, from the repository root, with `$T` an empty scratch directory:

```sh
qpdf [MODE] demo/contract.pdf $T/r.pdf
python3 -m warrant_pdf verify $T/r.pdf --trust demo/trust.json
pdfdetach -save 1 -o $T/b.json $T/r.pdf
python3 -m warrant_pdf verify $T/b.json --trust demo/trust.json
{ cat demo/contract.pdf; printf 'START_TAIL_MARKER{"x":1}END_TAIL_MARKER'; } > $T/tail.pdf
qpdf [MODE] $T/tail.pdf $T/t.pdf && grep -a -c START_TAIL_MARKER $T/t.pdf
```

Not measured: viewers that save (Acrobat, Preview, browsers), printing to PDF,
other rewriters (mutool, Ghostscript).
